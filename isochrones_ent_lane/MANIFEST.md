# Snapshot of the isochrones ENT lane

Verbatim copies of the 110 tracked files deleted from `mufflyt/isochrones` by PR #1329 (chore/remove-ent-lane, base `f997191da`, 2026-10-10): the ENT registry-validity work (ENT, otolaryngology, ENThealth, ABOto/ABOHNS, mystery caller cohort and power calculators). Paths are preserved relative to the isochrones repository root. They are kept here so the ENT study is self-contained; most scripts need the isochrones environment (NBER DuckDB, `R/utils/*`, `load_paths()`) and are not runnable from this directory as-is. Files that isochrones kept on purpose (`R/loaders/load_enthealth_data.R`, `R/strategies/strategy_ent_nppes_cache.R`, the specialty-profile config) are NOT here; read them from isochrones.

The specialty-agnostic parts of this lane now live in the `mysteryroster` package; `scripts/05b_validity_mysteryroster.R` in this repository is the rewired analysis.
